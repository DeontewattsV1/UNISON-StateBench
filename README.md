# Recognitive Field

Interactive HTML implementations of the Recognitive Field system — a spatial cognitive interface for agent perception and environmental awareness mapping.

## Files

| File | Description |
|------|-------------|
| `recognitive-field-v2.html` | Version 2 — core field rendering and interaction model |
| `recognitive-field-v3.html` | Version 3 — enhanced with updated perception layers and improved UX |

## Usage

Open either HTML file directly in a browser — no build step required. Both are fully self-contained.

```bash
open recognitive-field-v3.html
```

## Versioning

- **v2** — Stable reference implementation
- **v3** — Current active version with improved field resolution and interaction handling

## Notes

These files are part of the broader Celestial Agent ecosystem. For the full agent runtime, see the `celestial_agent_desktop_upgrade` repository.
