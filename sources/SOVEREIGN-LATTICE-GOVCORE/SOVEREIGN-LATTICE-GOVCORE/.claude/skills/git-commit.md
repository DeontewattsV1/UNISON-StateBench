## Format
```
<type>(<scope>): <short description>
```

## Types & scopes
- `feat(governance)` — new policy rule or approval workflow
- `feat(agents)` — new bounded agent capability
- `feat(reasoning)` — new reasoning lane
- `fix(security)` — zero-trust or signing fix
- `test` — test additions
- `docs` — CLAUDE.md, guides
- `chore` — CI, deps, tooling
