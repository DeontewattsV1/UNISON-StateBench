# UNISON Guardian v0.2.0 packages

They are stored on the `artifacts/guardian-v0.2.0` branch and linked from the Guardian GitHub release.
Verify downloaded files with `SHA256SUMS.txt`; the manifest records each artifact's size and digest.

The source archive contains the public repository. Existing StateBench code outside `guardian/`
is prior work under MIT. The new Guardian component is Apache-2.0. The Worker archive includes
its Apache license, NOTICE and bundled dependency licenses. These packages do not relicense
either component or include the separately supplied confidential research archives.
