# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 0.1.x | Yes |

The 0.1.x line is the supported release. The frozen v0.1 corpus and constitutional core are content-addressed; newer work on the default branch is included in that support.

## Reporting a vulnerability

Report security issues privately to **deonte@goodshyt.fun**.

Include:

- what the issue is and what it affects
- the path, version, or commit
- steps to reproduce, if you have them

Please do not open a public GitHub issue for an unfixed vulnerability. You will get an acknowledgment once the report has been reviewed.
